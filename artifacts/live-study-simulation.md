# Проверка живой ленты обучения

Прогон реального trainer service с IndexedDB, виртуальными днями и FSRS, без подмены планировщика. Ответы синтетические; оценка памяти вычисляется FSRS, это не измерение памяти человека.

## Проверяемые инварианты

- Плановая проверка не происходит раньше срока FSRS.
- Разбор ошибки не изменяет память FSRS и дневной лимит нового.
- Повторная отправка ответа не изменяет память повторно.
- Подсказка не получает самостоятельный зачёт.
- Лента не завершается с доступными ошибками. Короткий визит может быть прерван пользователем до завершения.
- Сумма самостоятельных попыток в памяти равна зачтённым ответам; новое не превышает лимит и не дублирует ID.
- Показ вопроса, ответа, найденных пар и закрытие прошлых показов выполняются через производственный сервис.

## Единицы учёта

Задание, проверяемое знание и правильный ответ — разные величины. Сопоставление из двух пар даёт одну самостоятельную проверку: последняя пара получается исключением. Полный набор значений считается одним составным знанием. Исправление первого неверного ответа не становится новой самостоятельной попыткой.

JSON содержит показатели по дням, форматам и вероятности вспоминания FSRS. Повтор объекта при разборе единственной ошибки допустим; число таких возвратов не означает повторный зачёт обучения.
