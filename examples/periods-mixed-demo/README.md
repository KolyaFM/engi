# Периоды XX века — смешанный тест

Вторая самостоятельная тестовая колода: 9 объектов, 11 диапазонов, 7 разных полей. Её можно включать одновременно с `periods-demo`.

| Объект | Поле | Годы |
|---|---|---|
| СССР | Существование | 1922–1991 |
| ГДР | Существование | 1949–1990 |
| Берлинская стена | Разделение Берлина | 1961–1989 |
| Корейская война | Боевые действия | 1950–1953 |
| Вторая мировая война | Боевые действия | 1939–1945 |
| Альберт Эйнштейн | Годы жизни | 1879–1955 |
| Нельсон Мандела | Годы жизни | 1918–2013 |
| Нельсон Мандела | Заключение | 1962–1990 |
| Нельсон Мандела | Президентство ЮАР | 1994–1999 |
| Аполлон | Пилотируемые полёты | 1968–1972 |
| Спейс шаттл | Пилотируемые полёты | 1981–2011 |

Все границы заданы с точностью до года. Источники указаны у каждого факта: NASA, Nelson Mandela Foundation, NobelPrize.org, Bundestag, Berlin Wall Foundation, Australian War Memorial, The National WWII Museum и Army.mil. Описания поясняют неоднозначные границы: стена — закрытая граница, не демонтаж; Корея — активные бои до перемирия; космические программы — пилотируемые полёты, не начало разработки.

У Манделы три независимых свойства одного объекта — проверка того, что варианты и результаты не склеиваются. Период Корейской войны совпадает с работой Никсона в Сенате из первой колоды: такие неразличимые диапазоны не должны попадать вместе в одно сопоставление.

Сборка:

```powershell
pnpm pack:build ./examples/periods-mixed-demo ./dist-packs/periods-mixed-demo-v1.engi
```

Импортируйте архив, выберите обе тестовые колоды и начните обычное смешанное обучение. Новые свойства оставляйте незнакомыми. Группы собираются из текущих учебных задач, поэтому не каждый экран обязан содержать оба пакета.

Проверка 20.10.2026: импорт обоих архивов отдельно и вместе; два сценария на70 и160 шагов для каждой комбинации, суммарно690 действий. Все сценарии прошли, внесённые ошибки исправлены; совместный длинный сценарий завершил23 свойства. Появление именно смешанных групп подтверждено трассировкой.
