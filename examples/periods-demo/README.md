# Периоды — тест механик

12 событий: восемь президентств США (Трумэн — Рейган) и четыре периода работы в Сенате. Источники Сената США указаны у каждого факта. Границы намеренно заданы годами, без месяцев и дней. Диапазон набора — 1935–1989; есть короткие, длинные, пересекающиеся и вложенные периоды.

Сборка:

```powershell
pnpm pack:build ./examples/periods-demo ./dist-packs/periods-demo-v1.engi
```

Для проверки импортируйте архив, выберите только эту колоду и начните обычное смешанное обучение. На новых карточках оставляйте свойства как незнакомые. Первые задачи появятся после знакомства с несколькими объектами. Колода разрешает выбор полного периода, дополнение границы и сопоставление полос. Формат выбирает планировщик, поэтому каждый следующий экран не обязан быть новым видом упражнения. Вспомогательная сетка самопроверки тоже может появляться.

Обычная хронология, свайп-категоризация, обратные вопросы и узнавание изображений отключены. Набор содержит 12 новых объектов: после дневной десятки оставшиеся два доступны при продолжении ленты.

Проверено 20.10.2026: импорт и два сценария на 70 и 160 шагов; во всех сценариях появились endpoint, choice и bands. В сценарии с ошибками они были исправлены; длинный сценарий завершил все 12 свойств.
