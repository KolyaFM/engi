# История США — 5 событий

Тестовая колода без изображений: пять коротких названий, подробные описания по ⓘ, пять годов и четыре связи с президентами. В 1776 году должности президента США ещё не было, поэтому у независимости это свойство отсутствует.

Предусмотрены вопросы в обе стороны, сопоставление и хронология. Доступность групповых заданий зависит от текущего обучения; все девять свойств не появляются одновременно. Описание справочное: открытие не меняет память и не считается подсказкой.

Сборка: `pnpm pack:build ./examples/us-history-5 ./artifacts/us-history-5.engi`.

Источники: [независимость](https://www.archives.gov/milestone-documents/declaration-of-independence), [Луизианская покупка](https://www.archives.gov/milestone-documents/louisiana-purchase-treaty), [прокламация](https://www.archives.gov/milestone-documents/emancipation-proclamation), [Аляска](https://history.state.gov/milestones/1866-1898/alaska-purchase), [гражданские права](https://www.archives.gov/milestone-documents/civil-rights-act).
