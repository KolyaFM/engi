# Конвейер и хронология в учебной ленте

## Что внедрено

Для доступных заданий распределения с двумя категориями компоновщик может собрать конвейер до 12 объектов. На экране один объект; ответ — свайп, нажатие категории или клавиши влево/вправо. Категории не исчезают по мере ответов, известной квоты 50/50 нет. Неверный объект возвращается в конец серии. Ответы сохраняются по одному; после перезагрузки уже решённые объекты пропускаются, ошибочные остаются после нетронутых.

Хронология во время обучения имеет два показа: вертикальный порядок 3–5 объектов и конвейер «до года / год и позже». Границы выбираются из сетки круглых годов, с более мелким шагом для близких событий. Ползунок убран из выбора форматов; старое сохранённое задание со шкалой при возобновлении заменяется вертикальной сортировкой без изменения памяти.

Для перетаскивания показаны выделение строки и место вставки. Порядок сохраняется после отпускания; кнопки вверх/вниз доступны как альтернатива жесту. Убран большой декоративный блок над последовательностью, чтобы пять строк помещались на мобильном экране.

## Подбор материала

Обычные сопоставления и конвейеры собираются из уже допустимых целей выбранной учебной очереди. Контекст хронологии собирается из готовых первых проверок конкретного свойства даты; другие незавершённые свойства не блокируют его появление. Разные свойства не смешиваются.

Для порядка разрешена максимум одна знакомая опора, только если она нужна для построения группы. Опора не входит в первичные цели, не получает зачёт или новое расписание. Наступившие точные повторения не заимствуются как опоры. Будущие подтверждения и свойства «Знаю» не используются для заполнения группы. Одинаковые годы не дают ложного строгого порядка; выбор альтернативы сохраняет приоритетный объект.

Контекст предлагается после примерно шести действий при наличии подходящих начальных целей. Разминка по завершённым знаниям не вытесняет доступные обычные проверки; после завершения доступной работы её период ограничен примерно восемью действиями. Число решений в группе учитывается при ритме. Материал не добирается до максимального размера только ради длинного задания.

## Зачёт и сохранение данных

Сопоставление и конвейер категорий сохраняют существующий независимый учёт каждого свойства: первая ошибка записывается отдельно, исправление на том же экране не становится новым успехом.

Для относительной хронологии введено `contextCredit` и ограниченное свидетельство `contextEvidence` с участниками, видом задания и границей. Успешный самостоятельный контекст заменяет начальное упражнение: свойство переходит к отложенному подтверждению. Оно остаётся «В обучении», пока подтверждение не завершено. Уже сохранённая память точного года не изменяется сортировкой или границей.

Текущая цель даты сохраняет прежнюю точность: после контекстного упражнения нужна одна самостоятельная проверка года не раньше пяти минут. Контекст сам по себе не создаёт FSRS-память года и не может закрыть подтверждение повторным контекстом. Полноценная долгосрочная цель относительного порядка — отдельное последующее расширение; здесь она не подменяет точный год.

Ошибки порядка не записываются всем участникам как забытые точные даты. Исправление после подсказки не получает контекстного зачёта. Обратная связь конвейера с границей не считается раскрытием точного года. Неверная последовательность, где интерфейс действительно показывает годы, учитывается как раскрытие.

Новый контекст хранится в необязательных полях существующей схемы lifecycle v1. Старые записи остаются допустимыми. Личная база не сбрасывалась, миграции с удалением данных и изменения старых FSRS-карт не выполнялись.

## Ограничения первой версии

Начальный контекстный зачёт подключён к датам с точностью до года и к требуемому навыку узнавания. Даты с более подробной точностью, приблизительные интервалы и отдельная долгосрочная память относительного порядка требуют собственных правил. Отдельный выбор хронологического формата по уже изученным датам остаётся практикой. Когда весь доступный материал завершён, бесконечная лента может использовать знакомые знания как явно обозначенную разминку; это не создаёт новых учебных обязательств.
