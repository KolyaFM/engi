# Разнообразие учебной ленты

## Подбор

Сроки памяти и активное обучение по-прежнему принадлежат общей очереди.
Новые форматы используют уже доступные свойства: незнакомые, отложенные и
отключённые знания не добавляются для заполнения группы.

- Сопоставление: минимум три разных объекта. Если подходящих объектов меньше,
  очередь выбирает одиночное задание.
- Конвейер с двумя категориями: от трёх до шести объектов. То же ограничение
  применяется к сортировке относительно года.
- В смешанной ленте после пяти экранов без «Вспомни» доступна учебная попытка
  вспомнить одно из свойств первой проверки. После девяти экранов без
  самопроверки доступна группа из трёх-четырёх совместимых свойств.
  Это условия допуска, а не обязательный цикл: ошибки, введение новых объектов
  и доступность данных сохраняют приоритет.
- При наличии другого готового объекта последний объект не повторяется
  только из-за небольшого различия сроков. История старого подборщика учитывает
  и исправления ошибок, включая переход между визитами.

## Что засчитывается

Учебное «Вспомни» использует существующее свойство, не создаёт вторую обязанность
для навыка recall и не повышает FSRS. Ответ «Вспомнил» без подсказки переводит
свойство на последующую объективную проверку через пять минут. Неверный ответ
или раннее открытие не дают этого перехода. Между проверками лента продолжается.

Самопроверка — отдельный формат `self_check`, контракт `practice-view` без
оцениваемых целей. Карточки переворачиваются независимо и сохраняются в черновике.
Продолжение не создаёт событие оценки. Открытие конкретной карточки регистрирует
показ только её ответа; активная проверка этого свойства откладывается на пять
минут, чтобы подсмотренный ответ не получил самостоятельный зачёт.

## Проверка

`tests/learning-variety.test.ts` проверяет размеры групп, появление новых форматов,
отсутствие лишних обязанностей и запрет зачёта подсказок.
`tests/learning-variety-browser.mjs` проверяет четыре настоящих флага, переворот,
восстановление, экран 320px и автоматическое раскрытие ответа после таймера.
Длинные модели обучения сохраняют проверки сроков, повторных отправок и ошибок;
`avoidableRepeatTrace` показывает контекст любого нежелательного повтора.
