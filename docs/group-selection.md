# Подбор групп

Планировщик передаёт сборщику только доступные свойства. Сборщик не меняет
сроки памяти, не добавляет будущие повторения и не вводит новые знания ради
заполнения группы. При недостатке участников остаются одиночные задания.

`group-affinity.ts` предоставляет общий контекст для сопоставления, категоризации
и самопроверки. Обязательная совместимость определяется по типу **показанного**
объекта, виду подсказки/роли изображения и типу ответа. Свойство, направление,
область обучения и разделение новых/известных целей сохраняет сборщик групп.
Ограничение не применяется к хронологии и сортировке относительно года.

Соседи выбираются последовательно по близости ко всей уже выбранной группе:
учитываются минимум и среднее попарного сходства. Общие конкретные теги важнее
общих широких тегов; цепочка родителей не умножает число совпадений. Теги,
содержащие отображаемые ответы или их псевдонимы, исключаются из расчёта.
Это проверка явного текста, а не семантическое распознавание всех возможных
подсказок в произвольных названиях тегов.

Общий пакет добавляет небольшой бонус, но не запрещает межпакетные группы.
Учитываются `originPackId` и все связи `installedPacks.entityIds`. Пользовательские
подборки не приравниваются к пакетам. Существующие сведения об импортах используются
без миграции базы и изменений формата архивов.

Совместные появления в последних восьми заданиях уменьшают предпочтение пары.
При равных оценках порядок случайный. Сопоставление сохраняет уникальные ответы;
конвейер содержит обе категории без обязательных равных квот. Запасной ответ
выбирается из того же совместимого набора. Сохранённые несовместимые группы
при восстановлении занятия заменяются новым заданием с сохранением уже записанных
результатов.

Включённая трассировка содержит сигнатуры группы и попарные оценки сходства.
Проверки: `tests/group-affinity.test.ts`, существующие тесты групп, моделей
обучения и браузерные сценарии сопоставления, конвейера и самопроверки.
