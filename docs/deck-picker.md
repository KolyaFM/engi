# Экран «Колоды»

Главный экран содержит двухколоночную сетку обложек и постоянные вкладки «Колоды» / «Статистика» с SVG-кнопкой настроек. Нажатие переключает участие
в обучении, меню редактирования на плитках отсутствует. Выбранные колоды сохраняются
в `appMeta.deckSelection`; время последнего запуска задаёт порядок при следующем
открытии. Переключение выбора не переставляет плитки. Обложки выбираются
детерминированно из основных изображений участников; без изображения используется
нейтральный фон. Карты и флаги помещаются целиком; фотографии заполняют плитку. Название имеет фиксированную область на две строки, счётчики и шкалы выровнены. Числовые суффиксы описания скрываются на плитке, сохраняя полное название в данных. SVG-галочка и отдельный передний G2-контур показывают выбор, независимо от обложки. Снизу закреплены общие счётчики и начало обучения.

## Область обучения

Сессия хранит `deckIds`. `deckStudyScope` вычисляет объединение разрешённых
единиц каждой колоды и передаёт его генератору как временный `Bundle.studyScope`.
Служебная колода не записывается в граф. Выбор учитывает свойства, распознавание
изображений и исключённые факты. Учебные участники ограничены этим объединением,
общие знания не дублируются. Посторонние варианты одиночного выбора могут
использоваться как контекст, но не получают зачёта обучения.

Дневной лимит нового общий. Начало обучения восстанавливает сохранённую сессию
только при совпадении выбранных колод. Изменение выбора создаёт новую сессию,
сохраняя результаты прошлой. Старые сессии без `deckIds` совместимы с прежними
API; новый экран запускает для них выбранную область явно.

## Прогресс

Процент считается по уникальным знаниям, прошедшим начальное обучение, и
свойствам, явно отмеченным «знаю». Обычное отключение не приравнивается к знанию.
Наступивший срок повторения не уменьшает процент. `propertyWorkload` является
общим источником показателей обучения и повторения для колод и ленты. Ошибки
фильтруются по области знания и не умножаются из-за повторных промахов.

## Геометрия

Общий слой использует `corner-shape: squircle` для округлённых поверхностей.
При отсутствии поддержки ResizeObserver и SVG-маски строят непрерывный контур;
по два кубических сегмента на угол с нулевой кривизной на прямых стыках и равной
кривизной на внутреннем стыке. Рамка использует тот же контур. Круглые элементы
сохраняют круглую форму. SVG-подложки не перехватывают указатель.

Проверки: `tests/deck-selection.test.ts`, `tests/decks-home-browser.mjs`, основные
модели обучения и браузерные сценарии заданий. Скриншоты находятся в `artifacts/`.
