# Колоды: свойства и дизайн — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking. Выполнять в текущем чате; не создавать дополнительные задачи или агентов без отдельного основания.

**Goal:** Пользователь выбирает свойства колоды, а экран колод, панель выбора и счётчики соответствуют одобренному макету.

**Architecture:** Личные настройки отделены от содержимого пакета. Структурный каталог общий для UI и сервисов, область обучения фильтрует задания и прогресс. UI использует один компонент счётчиков и существующие G2-примитивы.

**Tech Stack:** React, strict TypeScript, Dexie, существующая локальная память FSRS, CSS/SVG, node:test и Playwright.

**Spec:** `../specs/2026-10-12-deck-property-selection.md`; `../specs/2026-10-12-decks-ui-and-property-settings.md`.

## Global Constraints

- Выбор свойств не удаляет прогресс, ошибки и расписание FSRS; «Знаю» не возвращается в повторение.
- Хранить настройки отдельно от `Deck.learning`. Формат .engi не менять.
- Идентификаторы свойств и колод стабильные; названия/теги не являются ключами настроек.
- Цвет повторения зелёный, иконка — две зацикленные стрелки; обучение — книга; ошибки — крестик.
- Фон `#F6F3EE`, поверхность `#FFFEFC`, акцент `#9983BA` с проверкой контраста; не добавлять шрифт или UI-библиотеку.
- Мобильные области нажатия минимум 44×44 px, список панели прокручивается отдельно от закреплённой кнопки.
- Существующие изменения рабочего дерева сохранять. Коммиты и публикацию без отдельного запроса не выполнять.

## Review Focus

- Объект в двух колодах: объединение включённых знаний без двойного счёта — задачи 2 и 3.
- Новые свойства того же объекта в одной сессии: новый эпизод, без повторного дневного расхода — задача 2.
- Обновление пакета и восстановление копии: личные исключения сохранены — задача 1.
- Закрытие/ошибка сохранения: черновик отменяется или сохраняется для повторной попытки предсказуемо — задача 4.
- iPhone, длинный список и увеличенный текст: фон не прокручивается, кнопка доступна, жесты ленты сохраняются — задачи 4 и 6.
