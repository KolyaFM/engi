# Энги 2.1 — обновление Study Feed

## Как заменить текущую версию

1. В действующей Энги сохраните `.engi-backup` и оставьте исходные `.engi`.
2. Распакуйте архив. Содержимое проекта должно оказаться в корне вашего репозитория. Сохраните собственную папку `.git` и настройки публикации. Архив не содержит пользовательской базы.
3. Выполните `pnpm install --frozen-lockfile`, `pnpm test`, `pnpm build`.
4. Для локальной проверки запустите `pnpm preview`, откройте `/engi/`.
5. Если публикуете на GitHub Pages, используйте прежний адрес и существующий процесс публикации. В этой задаче публикация не выполнялась.
6. В работающей PWA согласитесь на обновление. Проверьте прежний прогресс и импорт пакетов, затем сохраните новую копию.

Схема IndexedDB остаётся v2. Новые поля попыток и калибровки необязательные; старые состояния и события не переписываются. Сохранённый текстовый Recall в активной ленте переводится в Recall-Reveal, старые конечные сессии закрываются без удаления истории.

## Что изменилось

- Choice/Match/Categorize/Missing: неверный вариант красный и отключён, правильный скрыт до выбора, попытки продолжаются в той же карточке.
- Одно событие на карточку; результат определяется первой попыткой. Все реальные ошибочные варианты собираются без повторов. У существующей памяти первая ошибка даёт Again; вынужденный верный ответ не превращается в Good.
- Новый неудачный pretest не создаёт Memory/lapse. Контекст из базы показывается около 1,6 секунды, затем задача возвращается после нескольких других карточек.
- Recall: 5000 мс активного времени, автоматическое раскрытие и жест оценки. Короткий жест отменяется; края экрана исключены. Пауза в фоне, подробностях и при недоступном изображении. Время восстанавливается, временный сбой сохранения раскрытия повторяется без нового отсчёта.
- Timeline: общая шкала, нейтральная позиция без утечки ответа, только явное подтверждение, компактные отметки пользователя и факта. Узкие кластеры дат не засчитываются автоматически.
- Отложенные исправления меняют способ проверки или дают различение двух спутанных вариантов; быстрый repair до срока не пересчитывает FSRS. Реальная путаница затухает после успешных объективных различений.
- В смешанной практике Recall распределён с промежутками, повторная уверенная самооценка проверяется объективными заданиями. При нехватке других форматов возможен только Recall.
- Плавное следование карточки пальцу, возврат, локальная реакция вариантов, короткий вход/выход, вступление к сложным заданиям. Уменьшение движения и доступные органы управления. Тихий звук выключен по умолчанию, вибрация необязательна.
- Дневная цель продолжает ленту. Главная предлагает один повод вернуться из реальных данных. Прогресс показывает охват, текущую сохранность, горизонты 7/30/90 дней и сегодняшние реальные переходы через 30 дней.
- Сравнение своей версии и обновления пакета с двумя действиями. Ошибочная версия не нарушает граф ссылок; изменение факта сбрасывает только его память.
- Удалены production generateSession/startSession/createRetry и текстовый Recall. Лента непрерывная, буфер ограничен, предзагрузка четырёх изображений.
- Сохранены локальные редакторы, пакеты/backup v1/v2, стабильные цели и история. Объекты без изображений остаются доступными даже в группах с изображениями; имена и изображения имеют отдельные корректные пулы.
