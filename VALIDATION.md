# Проверка Энги 3.0

Проверено 2026-10-07, Node 24.19.0 в среде сборки. Минимальная версия проекта — Node 22.13+.

## Результаты

- `npm test` / `pnpm test`: 103 теста прошли, 0 ошибок. Дополнительно `scripts/check-learning.mjs` проверяет генерацию, допустимость и оценку семи прежних форматов.
- `npm run build` / `pnpm build`: TypeScript и production-сборка проходят. Workbox создаёт service worker и кеш приложения. Есть некритичное предупреждение Vite о размере основного JS chunk.
- `tests/browser-v3.mjs`: Chromium, 1365×900 и 390×844; импорт v3, предварительный просмотр, два пакета с общими сущностями, повторный импорт, отдельные колоды, настройки обучения, множественный ответ с отдельными результатами двух фактов. Ошибок страницы не обнаружено.
- `tests/production.mjs`: реальная production-сборка; legacy .engi через bundled worker, PWA service worker, офлайн-перезагрузка, локальная картинка, знакомство, дневной бюджет, повторение на следующий день и продолжение текущего задания.

В браузерной проверке использовался Chromium 153 из временной среды; браузерный бинарник не включён в проект.

## Новые сценарии

Отдельная серия `tests/architecture-v3.test.ts`: имена и алиасы, два пакета / один автор, повторный импорт, переименованные сущности и колоды, одноимённые произведения с уточнениями, коллизии алиасов, конфликты значений, точность дат, совместимость полей, источники без дублирования, независимые колоды, полные многозначные наборы, исключения фактов, транзакционный откат и очистка медиа, полное восстановление, консервативное объединение и миграция базы v3 → v4.
