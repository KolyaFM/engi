# Энги 3.0

Локальный тренажёр знаний: React + TypeScript + Vite, Dexie / IndexedDB, Cache Storage, FSRS и PWA. Версия 3.0 вводит декларативные пакеты, общую базу сущностей и самостоятельные колоды.

## Запуск

Node.js 22.13+ и pnpm 10.30.1:

```powershell
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

Открыть http://localhost:5173/engi/. Папка `node_modules` в архиве не требуется: зависимости восстанавливаются из `pnpm-lock.yaml`.

```powershell
pnpm test
pnpm build
pnpm preview
```

Готовая сборка находится в `dist/`; preview — http://localhost:4173/engi/. Для обновления опубликованного приложения требуется заново разместить сборку на прежнем адресе. Данные разных адресов и браузеров независимы.

## Что изменилось

- `.engi` с `schemaVersion: 3` описывает знания именами, типами и алиасами; внутренних ID в нём нет.
- Импорт сначала показывает сопоставление и расхождения, затем сохраняет весь граф одной транзакцией.
- Совпадающие факты и источники объединяются; похожие строки не склеиваются автоматически.
- Колоды имеют собственные таблицы, состав, выбор изучаемых свойств и исключения. Теги остаются метками.
- Несколько произведений могут ссылаться на одного автора. Неоднозначные обратные вопросы не создаются.
- Для явно полного набора нескольких значений есть формат «Несколько ответов» с отдельной памятью каждой связи.
- Ручное объединение дублей переносит ссылки, изображения и участие в колодах, сохраняя историю.
- Полная копия `.engi-backup` v3 сохраняет знания, все изображения, колоды, прогресс и настройки.
- Старая база мигрирует в версию 4 с сохранением внутренних ID. Старые пакеты 1/2 и копии 1/2 читаются.

## Пакеты

Создайте папку с `bundle.json` и изображениями в `media/`. Для нового формата `manifest.json` можно не писать: сборщик создаст его с хешами файлов.

```powershell
pnpm pack:build ./examples/coauthors ./my-pack.engi
```

В `examples/` находятся два готовых `.engi` и исходные JSON. `coauthors.engi` содержит вымышленные данные для проверки обучения; `van-gogh.engi` показывает структуру реального контента, сведения отмечены непроверенными. В этих примерах нет изображений.

## Проверки

```powershell
pnpm test
pnpm build
pnpm test:browser:v3
```

Для браузерной проверки сначала запустите `pnpm dev`; установите Chromium через `pnpm exec playwright install chromium`. При необходимости задайте `ENGI_TEST_URL` и `ENGI_BROWSER_PATH`. Скриншоты проверок сохраняются в `artifacts/`.

Данные находятся только на устройстве. Перед обновлением сохраните копию; очистка данных сайта удаляет базу и Cache Storage. Автоматической синхронизации между устройствами нет.
